Connect GoatCounter

This page reads your visitor numbers from GoatCounter. It needs an API token once. The token stays in this browser and goes only to GoatCounter.

  1. Open GoatCounter’s API settings (sign in if asked).
  2. Create a new token. Name it “Stats page” and tick only Read statistics.
  3. Copy the token and paste it here.

Use this page on another device by pasting the same token there.
